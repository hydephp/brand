HydePHP brand marks
===================

Fonts (both SIL Open Font License, free for any use):
  Editorial  Playfair Display Bold 700   fonts.google.com/specimen/Playfair+Display
  Grotesk    Schibsted Grotesk Bold 700  fonts.google.com/specimen/Schibsted+Grotesk
  "Cloud"    same family, Regular 400

Three marks
  hydephp-editorial-<light|dark>.svg       HydePHP, System A (Victorian site, print)
  hydephp-grotesk-<light|dark>.svg         HydePHP, System B (current site, docs, GitHub)
  hydephp-cloud-grotesk-<light|dark>.svg   HydePHP Cloud, System B only
  hat.svg                                  symbol only

  HydePHP Cloud is always System B. There is no Editorial version of it.
  "light" = artwork for light backgrounds (navy type)
  "dark"  = artwork for dark backgrounds (white type)

Geometry
  Cap height c = 100 units. Hat height 1.55c, gap to the H 0.45c,
  hat optically centred on the cap band. Clearspace 1c on all sides.

Fonts are embedded
  Each SVG carries a subsetted, base64-embedded copy of the font it needs
  (only the glyphs in the wordmark), so the files render correctly anywhere
  with no font installed. The wordmark is still live text if you need to edit
  it in Illustrator / Figma / Inkscape.

Colour
  Ink   #141E30    Paper #FFFFFF
  Mist  #C3CCDC    ("Cloud" on dark)
  Slate #5F708C    ("Cloud" on light)
  Band  #8A2387 -> #E94057 -> #F27121   (hat only, never the type)
